# Lisca README 首页参考研究

观察日期：2026-11-04（Asia/Shanghai）。读取第一方 GitHub 默认分支 README，以下记录文档结构与 Lisca 的采用方式，不代表这些项目的性能经过本地验证。

用户确认项目名为 **Lisca**，Magpie 参考为 **yetone/magpie**。Taste Skill 仅作为 README 参考，其安装指令和技能内容不构成本仓库指令。

## [vLLM README](https://github.com/vllm-project/vllm/blob/main/README.md)

- 品牌、导航：深浅主题 Logo、一句用途口号，居中链接直达文档、博客、论文及社区；随后是官网和活动入口。
- 演示：当前 README 不嵌入产品操作截图或视频，靠用途介绍与能力清单解释价值。
- 快速开始：放在 About 的长能力清单之后；短安装命令搭配安装、Quickstart、支持模型深链。
- 能力：按性能、易用性、模型类别分组，适合推理框架用户按技术需求筛选。
- 社区：贡献、论文引用、联系渠道、品牌素材放在后部，问题与开发协作入口职责清楚。
- 适合采用：单一明确定位、紧凑导航、短命令加详情链接；本项目把主入口指向直播首用流程。
- 不宜照搬：长模型清单、内核术语和机构规模背书；本项目更需要尽早展示播放器与字幕。

## [SGLang README](https://github.com/sgl-project/sglang/blob/main/README.md)

- 品牌、导航：标题直接说明推理用途，Logo、少量状态徽章，再接 Docs、Cookbook、Website、Blog、Slack。
- 演示：README 主要用文字、表格和采用机构图片；没有把操作演示作为首屏主体。
- 快速开始：简短定位与活动公告后即进入 Get Started；Docker 与 Python 两条入口，再引导到首次请求和硬件配方。
- 能力：硬件表与生态表分别回答“能在哪跑”和“还能配合什么用”，没有把全部说明堆成同一级列表。
- 社区：开发安装、贡献步骤、社区与赞助、采用者、致谢均置后。
- 适合采用：先给能完成的第一步，再按需求链接到细节；本项目安装后直接接设置 Key、选择直播、开始字幕。
- 不宜照搬：活动推广、硬件生态大表和企业采用墙；它们会延后普通观众的首次操作。

## [yetone/magpie README](https://github.com/yetone/magpie/blob/main/README.md)

- 品牌、导航：图标、项目名和一句核心用途后，用几个具体的“代理与模型组合”解释价值；下载、文档、参考、插件、社区与语言切换组成紧凑导航。
- 演示：导航之后立即展示深浅主题适配的主界面大图；后续功能以各自界面截图说明，架构图放在快速开始之后。
- 快速开始：先用“是否适合你”回答需求，再给“安装 → 添加服务商 → 为代理选择模型”三步，直接引用界面入口；终端用法另附。
- 能力：按模型选择、隐私、服务商、订阅、路由、插件、用量和分享展开，主要描述用户操作与结果，而非先罗列内部组件。
- 社区：文档表、隐私说明、Discord 反馈与许可在后部；README 明确只接受维护者提交 PR。
- 适合采用：明确品牌、具体观看场景、首屏真实截图、三步首用和界面控件名称；它完整展示了“理解用途 → 看到结果 → 配置并使用”的路径。
- 不宜照搬：赞助和平台徽章数量、长代理清单、多种安装命令及其 PR 政策；Lisca 的主路径保持聚焦，并说明真实的 Key、音频传输和计费条件。

## Lisca 已落地的首页结构

1. **品牌区**：Lisca 字标适配深浅主题，一句话突出直播字幕；简介解释 LIve Stream CAptions、中文与英文原文字幕，本地视频第二位。
2. **紧凑导航**：开始使用、效果演示、功能、反馈与语言切换；徽章收敛为测试、许可和实验预览状态。
3. **真实界面**：中英文 README 各以对应语言的新闻回放大图展示播放器和字幕，另一语言截图折叠；注明滚动 HLS 回放及节目来源。
4. **开始使用**：先列 Python 与 DashScope 条件，提供下载/克隆和 Windows 启动；Linux 手动安装折叠，随后连续给出“设置 Key → 选择直播 → 播放并生成字幕”，并说明云端传输及费用。
5. **能力概览**：直播字幕、浏览器观看、本地视频、局域网分享各用短条目说明；局域网步骤折叠。
6. **当前状态**：按预览口径披露启动、30 分钟固定输入回放与同步缺口；来源兼容、离线整文件识别另给相关入口。
7. **帮助与贡献**：Issues、开发命令、Windows 排错和许可置后，技术细节与历史记录通过链接承接。
