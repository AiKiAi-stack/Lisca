## 问题清单

### 严重（会让人做错决定）

- **A1 状态栏与画面矛盾。** 画面已经出现「演示字幕 03」，底栏仍写「暂未识别到语音，继续播放」（[09](../assets/2026-11-24-webui-audit/09-playing.png)）。`index.html` 的 `status` 文案由识别进度与播放守卫分别写入，没有单一状态机；真实识别时同样可能出现「未识别到语音」而字幕在滚动，用户无法判断字幕是否可信。
- **A2 主行动不固定。** 「播放并生成字幕」与「打开文件」「结束观看」并排（[01](../assets/2026-11-24-webui-audit/01-home.png)）；从频道弹窗选台会关闭弹窗并回填 URL，用户要再点一次才播放（[02](../assets/2026-11-24-webui-audit/02-channels.png)）。主按钮随状态变化，但视觉权重始终相同。
- **A3 频道弹窗把两种任务挤在一起。** 「加载频道」（取列表）和「批量检测」（体检）同级放置，进度、完成、取消全部写在 `#chInfo` 一行（[03](../assets/2026-11-24-webui-audit/03-batch-running.png)、[04](../assets/2026-11-24-webui-audit/04-batch-cancelled.png)）；完成后只显示「批量检测完成 60/60」，没有成功/失败数，失败行只能逐条看 ❌。

### 中（增加操作成本）

- **B1 工具条同权重。** 复制观众链接、字幕开、字幕样式、字幕记录、全屏排成一行（[09](../assets/2026-11-24-webui-audit/09-playing.png)），toggle、浮层、模态弹窗、全屏四种交互没有分组。
- **B2 频道列表不落库。** 加载后的 M3U 只在页面内存（`index.html` 的 `channels`），关闭页面即丢；侧栏「最近观看」只保存 20 条单 URL（`source_library.js`），不能代表一次合辑。用户每次都要重新粘贴地址并重新检测。
- **B3 取消态弱。** 「取消检测」沿用放大镜图标，只靠文字和 `aria-pressed` 区分；取消后的行写「已取消」，但已完成的 ✅ 行与失败行混排，没有汇总。
- **B4 大列表不可导航。** 60 行已需要滚动，839/11473 个频道没有搜索、分组跳转、只看失败/按延迟排序（[02](../assets/2026-11-24-webui-audit/02-channels.png)）。
- **B5 操作记录是纯文本。** 虽有类型筛选与导出（[11](../assets/2026-11-24-webui-audit/11-operation-log.png)），但时间线与请求混在一个 textarea，缺少按动作过滤、失败高亮、定位到具体请求。
- **B6 提示信息重复且位置分散。** 空状态、底栏状态、`#sourceBufferStatus`、`#lateCaption` 四处都在讲"现在发生了什么"（[01](../assets/2026-11-24-webui-audit/01-home.png)）。

### 低（打磨）

- **C1 状态样式单一。** `#status` 12px 灰色，正常/等待/错误共用同一位置，错误只靠 `.err` 变红（[09](../assets/2026-11-24-webui-audit/09-playing.png)）。
- **C2 隐藏但占位的控件。** 「复制观众链接」`display:none` 但保留在工具条顺序里，分享地址下拉只在 2 个以上地址时出现，工具条宽度随状态跳动。
- **C3 设置里的成本提示不够近。** 「检查连接（会调用云端 API）」与「应用配置」同权重（[07](../assets/2026-11-24-webui-audit/07-settings.png)），费用说明在段落里而不是按钮旁。

## 改版方向

### 方向 A：状态驱动的主控条（推荐）

- 主行动固定一个按钮，按状态切换：`播放并生成字幕` → `准备字幕…（禁用 + 进度）` → `结束观看`；次行动（打开文件）降为文字按钮。
- 工具条分三组：**字幕**（开/样式/记录）、**视图**（全屏）、**分享**（复制观众链接）；同组用分隔线，浮层与弹窗用同一层级。
- 单一状态机输出文案：准备中 / 播放中 / 字幕等待 / 降级 / 已结束 / 错误。状态栏不再被多处写入。
- 可证伪检查：主按钮同一时刻只有一个主色；识别中不再出现「未识别到语音」与可见字幕并存；工具条 aria-label 无重复。

### 方向 B：片源库 + 片源管理页

- 一次加载的 M3U 成为可命名的列表（本地持久化），侧栏显示列表而不是单条 URL；「最近观看」升级为「列表 + 频道」。
- 「批量检测」移出播放弹窗，进独立管理页：搜索、只看失败、按延迟排序、汇总成功率；结果按列表保存。
- 观看区只保留当前选中的片源，减少「弹窗选台 → 关弹窗 → 再点播放」。
- 可证伪检查：刷新页面后列表与检测结果仍在；11473 条列表可搜索/筛选；成功率汇总可见。

### 方向 C：一次性任务引导

- 首屏 3 步：选来源 → 检测/预览 → 播放；引导结束回到常驻布局。只适合首次使用，不能替代 A/B。

**推荐顺序**：先做 A 的一个小切片（主按钮状态机 + 工具条分组 + 状态文案），再做 B 的第一半（列表命名与持久化）。C 只做首次出现，避免长期占屏。

## 不在本提案

- 不改识别、翻译、字幕时间轴与去标点行为（已在 #109 定义）。
- 不引入账号与云端同步；操作记录仍只在本机（#111）。
- 不做合规审计、远程上报。
