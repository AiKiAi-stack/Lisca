# 固定参考语音的有声区间估计

这两份文件是代理在实际字幕同步计分之前冻结的声音分析结果，分别覆盖用户已确认文字与声音对应的中文59条、英文67条。它们不是人工起止真值，也不表示同步、95%覆盖或发布通过。完整原始声音及分析审计保留在本机；不在这里发布音频。

每语保留78个实际模型有声区间，未用“第一段起点到最后一段终点”的包络填平中间停顿。每个起止点都保留不确定度；阈值变化表示估计器敏感性，不是统计置信区间。源文件 SHA-256 与已确认参考清单相同，顺序和全部126条均保留，不删除难例。

## 方法与保留的未知

- 使用 Silero VAD 官方 ONNX 模型，提交 `066409f3d9db45a30d21dfcbf9147826ffdd7052`，模型 SHA-256 `1a153a22f4509e292a94e67d6f9b85e8deb25b4988682b7e174c65279d8788e3`，MIT许可。ONNX Runtime 1.31.0，仅CPU；16kHz单声道，512样本窗口、64样本上下文，每条重置状态。
- 在读取字幕结果前声明0.35、0.50、0.65阈值和官方滞回/填充规则。保留0.50实际支持区间，比较阈值族及旧WebRTC方法；后者只是分歧检测，不是真值。
- 最初的一对一整段匹配将不同切分误算成大幅边界不确定；旧v1/v2诊断原样保留。v3分别核查外侧边界和内部切分，代理对剩余22条前端分歧查看波形与频谱，依据预先声明的谐波、共振峰、音节变化与噪声规则分类。没有用ASR词时间或字幕分数反推起止点。
- 中文第12、39、51条，英文第10、54条的外侧起点仍无法可靠缩小至0.5秒内；保留未知。另有内部切分敏感性，均留在逐条审计中。56条中文、65条英文的外侧两端不确定度在0.5秒内，不保证这些条目的字幕偏差通过。
- 所有126个原始分轨都通过文件哈希及其与全长WAV对应切片的PCM一致性检查；无声信号在三个阈值下的自检均未产生语音。
- JSON坐标保留6位小数；英文7个末端因小数取整比清单精确末端多0.5微秒。文件及哈希不变，读取时仅允许1微秒内的序列化误差并裁至清单边界；更大的越界无效。这远小于一个16kHz采样点，不改变字幕指标或声音不确定度。
