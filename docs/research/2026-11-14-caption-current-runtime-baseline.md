# 整句体验候选前：当前应用真实基线

- 日期：2026-11-14。
- 应用候选：`79504994e477a842e9509f4941dc9d2f2c46348b`，采集时应用代码与该版本一致。
- 原验收项：开播前准备完整字幕、避免播放先行和有界等待。
- 本次假设：当前应用的 2 秒降级会在字幕 ready 前启动播放；延长完整句观察能补足旧 6 秒窗口缺少终稿的证据。
- 决策用途：为 #102 准备状态提供真实反例；为 #103 固定同输入候选对比提供基线。

## 运行与输入

本机唯一 WebUI 为 8002，配置只在应用内存保存；授权凭据路径与读取方式见[本机凭据](../guides/local-asr-credentials.md)。

使用固定原速中文、英文参考前缀，经 H.264/AAC 编码为分片并按源时钟逐片公开的回环 HLS。中文、英文各一次成功真实识别；每次设置 35 秒观察上限。它们最终均报告正常 completed。具体 WAV、编码/解码身份与录制/报告哈希见[机器摘要](2026-11-14-caption-current-runtime-baseline.json)。

中文在更长观察中已收到终稿。此前 6 秒历史窗口中的“未观察到终稿”继续保留，当前新结果只支持此候选、输入和环境。

## 失败与运行关闭

英文首次采集在页面导航时连接 8002 被拒绝，HTTP 识别会话创建为 0、采样为 0，状态为 measurement_invalid。原报告及录制保留。检查发现原服务与素材服务均已退出；改用记录 PID 的独立会话进程启动并确认 8002 HTTP 200，再另存英文第二例，没有覆盖失败记录。

成功案例均走到正常 completed，DELETE 列表为空。该观察支持正常完成，不能额外写成 DELETE 200 或所有 SDK 关闭路径已验证。采集器退出后服务保留用于下一轮候选；下一次改 WebUI 前需检查活动会话及进程所有者。

## 适用范围

本轮是有限当前基线。每语一次不能产生有效的 20 次启动 P95，不证明长时观看、英文快语速资格、独立声音同步或覆盖率。句子提交回放和新策略真实候选另列各自结果。
