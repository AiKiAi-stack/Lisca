# 本轮采用浏览器输出时钟的字幕同步估计

状态：已接受（2026-11-18）。

用户选择按浏览器输出时钟推进本轮工程测量：对照实际输出语音与可见字幕的起止时间，结果明确标为浏览器时钟估计。此口径使本轮观看体验能够继续自动计量，同时保留物理音箱延迟、旧 source-domain 指标与 #70 正式声学校准的原有未知和失败结论。

新采集以带帧位置的无损 PCM 保存输出音频，实际像素观察保存字幕区间，独立记录内容归属、缺失、重复、时钟及边界不确定度。参考身份、59/67 分母、至少 50 句及 0.5/1 秒、95% 原门槛保留；新结果单独命名和留证，不能将浏览器 API 估计写成已证明的固定毫秒精度，也不能以当前实际输出时长替换参考分母。

技术依据及尚待验证的捕获桥见[测量提案](../research/2026-11-18-browser-clock-sync-design.md)。旧采集原点歧义和五项 VAD 起点未知继续保留，预算与版本发布责任分别判断。
