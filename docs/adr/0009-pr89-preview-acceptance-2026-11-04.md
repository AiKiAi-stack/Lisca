# ADR-0009：PR89 预览验收门槛调整（启动 5.5 秒、长时回放、同步保持开放）

- 状态：已接受（2026-11-04 用户明确要求修改 spec 后合入 main）。
- 范围：PR89 代码切片/实验预览；不改变正式首版 #46 的发布门槛。

## 背景

PR89 合入 main 后，正式验收仍卡在长时观看、启动延迟和音画字幕同步。2026-11-04 对候选 `027b3254cc56cc7ea58b1e2066958e86481cc6a0` 重新执行了真实测量：

- 每语 20 次固定 HLS 真实启动：中文 P95 5013.9 ms、英文 P95 4470.3 ms，均超过原 3 秒门槛；20/20 有效、0 错误。
- 独立只读复核定位到 provider 首个完整短语：中文 +4274.3 ms、英文 +3272.2 ms；应用显示仅增加 4/26 ms，稳定策略增加 530/1012 ms。即使本地延迟归零仍为 4375.8/3373.6 ms。要满足 3 秒只能发布未完成草稿、换素材或换更低延迟的识别服务。
- 中文固定参考真实浏览器同步采集完成，但评分器因播放期间 9 次短暂停顿（总 3.73 秒）无法把音频对齐到两个以上锚点，返回 unknown；没有 50 句有效同步样本。
- 中英各 30 分钟固定输入实时回放完成：0 错误、采样有效、无来源缓冲；前后 5 分钟延迟代理增长 -0.044/-0.228 秒。代理不是独立声学真值，cap 取消不是正常 EOF。

## 决策

1. **启动**：PR89 预览门槛改为每语 20 次、P95 ≤5.5 秒；3 秒保留为未来目标。保留冷/热、HLS 来源、采样、冻结与附加播放延迟报告。未来 provider/模型变化后仍按 3 秒复测。
2. **长时**：PR89 预览接受固定输入实时回放的中英各 30 分钟稳定性证据；要求 0 公开错误、50 ms 采样有效、无来源缓冲、延迟代理增长 ≤1 秒，并披露代理方法与缺口。公网 HLS 30 分钟仍在来源矩阵中单独验收。
3. **同步**：门槛不变（每语 50 句、P95 ≤0.5 秒、最大 ≤1 秒、覆盖 ≥95%），当前 unknown。它**不是 PR89 预览合入的阻塞**，但仍是正式发布 #46 的阻塞；任何材料不得写成已通过。
4. **发布范围**：本轮只能称实验预览/代码切片，不更新正式发布标签；保持已知限制与剩余风险。

## 影响

- PR89/main 可按预览范围合入与部署；#34/#44 的启动与长时稳定性可在新门槛下记录为预览通过；#63/#46 保持开放。
- 该调整是用户授权的验收口径变更，不是把测得值自动写成门槛；原 3 秒目标、旧失败、同步 unknown 和公网来源缺口的证据全部保留。
- 若用户不接受 5 秒级启动或要求正式发布，必须先更换识别 provider/模型或重新打开门槛讨论，不能复用本 ADR 宣称低延迟或正式首版通过。
