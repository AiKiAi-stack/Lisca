# ADR-0005: 局域网共享直播会话

- 状态：已接受（2026-10-18）

## 背景

用户希望把带实时字幕的直播发给同一 Wi-Fi/局域网中的其他设备观看。让每个观众各自启动页面会重复拉取音频并启动 ASR；而把管理页面直接暴露给局域网则会让观众获得直播控制能力。

## 决策

1. 主机只启动一份直播及 ASR 会话；观众通过随机、只读的观众链接加入。
2. 管理控制仅允许主机本机访问；观众链接仅在 WebUI 服务所在的局域网可访问。
3. 同一时刻最多允许 3 台观众设备连接。每台观众独立播放视频，但字幕来自同一 ASR 会话。
4. 观众加入时从当前直播位置开始。停止直播或处理自然结束后，链接立即失效；下一场直播使用新链接。

## 后果

- ASR 上游连接和实时识别只运行一次；视频由主机代理给每台观众设备。
- WebUI 需监听局域网接口，同时将控制路由限制为本机请求，并将观众媒体代理限制为该会话已登记的媒体资源。
- 观众设备消耗主机的网络上行带宽；本决策面向最多 3 台观众设备的小范围内网观看。
