# ADR-0006：云端翻译显示当前语句，不以终稿阻塞播放

- 状态：显示策略已由 ADR-0007 取代（2026-10-21 用户实看后纠正）；云端配置、语言与停止请求约束继续适用。
- 范围：新的云端翻译模式；旧识别/演示模式继续兼容 ADR-0004。

## 背景

公开用户需要中文与英文双向翻译，并已确认可以接受当前语句逐步显示和修正。
ADR-0004 等待稳定短句或终稿来推进播放上限，其等待策略不能直接作为低延迟产品的验收要求。
同时，译文语序与原文可能不同，原文的逐字时间戳不能直接套到译文词语上。

## 决策

1. 首版复用 FunASR 的源句编号和时间轴，使用 Qwen-MT Flash 流式翻译；逐块显示目标文本。
2. 翻译按原语句关联，当前语句允许修订；完成语句的终稿不接受后续草稿覆盖。
3. 同一句等待处理的识别草稿合并、节流；待处理语句数量有上限，持续落后时停止新请求并显示错误。
4. 云端翻译模式不发送 ADR-0004 的字幕放行上限，不等待整句翻译才允许播放。保留迟到、同步偏差的测量，不把无播放闸门宣称为已达到低延迟或严格同步。
5. 本地视频跳转时重新建立当前时间位置的识别与翻译会话，旧连接事件不得进入新会话。
6. 仅承诺显式选择的中英双向能力；其他语言、自动语种检测、替代实时语音翻译模型须另行验证。

## 后果

观众能先观看并逐步获得译文；翻译较慢时字幕可能晚于声音，不能靠不断冻结画面掩盖这种偏差。
时间范围未确认的译文草稿及已经迟到的译文在独立、明确标注的阅读区显示，不叠到不相干的当前语音上。
同一句多次识别修订会产生额外翻译调用，必须显示云端计费提示，并在停止时阻止新请求。
真实 API 效果、延迟、稳定性与质量仍需有授权的样本验收，模拟服务只验证协议和用户流程。
