# ADR-0007：视频内显示完整短句，按阅读时间换页

- 状态：已接受（2026-10-21，用户明确要求字幕上屏、避免整段闪出闪退、正式字幕不要逐词生成）。
- 取代 ADR-0006 中逐词草稿上屏及独立迟到译文框的显示决策。继续保留云端计费告知、停止闸门和显式语言组合。

## 决策

1. 复用稳定短句原则：连续两次识别一致的完整分句可提交翻译；无标点的持续讲话按有界短语切分；语音终稿只提交尚未释放的尾部。已稳定原文被纠正时重新映射分句边界，防止吞掉尾部；纠正也须重复稳定或终稿后，才发布完整句子的翻译修订。删去的原文会撤回其译文；新修订保留原有排队位置。当前页不会被逐词更新抢占。若已稳定的原文随后被识别纠正，重新映射分句边界，防止插入或删除吞掉尾部；纠正也须重复稳定或终稿后，才发布完整句子的翻译修订。当前页读完前不会被修订抢占。词时间可用时保留时间；缺失时不伪造译文逐词时间。
2. Qwen-MT 仍可在内部流式接收，只有翻译完成后才发送正式字幕。正式字幕不逐词更改，亦不显示在播放器下方。
3. 视频叠层每页最多两行译文；开启双语时额外显示一行原文摘要，完整原文与译文在记录查看。页面按照实际宽度和字号重排。
4. 以阅读负荷决定每页 2.4–8 秒的停留时间。新字幕不得抢走尚未读完的当前页。暂停冻结阅读时钟；跳转、停止和换源清空旧字幕队列。
5. 连续过载时保持当前页阅读时间，待显示字幕预算最多约 14 秒，直播直播超出时跳过最旧待显示页并明确提示；最近 200 条记录保留完整短句供回看。此直播取舍可能遗漏视频叠层内容，不能声称严格同步或无损显示。本地文件保留所有待显示页，允许继续阅读到视频结束之后。云端翻译请求队列另保留 ADR-0006 的 32 项保护上限，持续处理落后时明确报错并停止新计费请求，不能将它与显示队列的跟进策略混为一谈。
6. 不设置固定几秒或十几秒的产品延迟。视频继续正常播放；真实译文到达时间与画面同步程度须测量，不能用界面修复宣称 API 延迟问题已消失。
7. 本地云端视频短暂停顿沿用原连接；长于 15 秒的用户暂停，或已知连接关闭，恢复播放时从暂停位置建立新识别会话。暂停字幕保持完整，正常播放时的真实服务错误仍显示，不做无限自动重试。
8. 播放器为默认主界面，云端配置、样式、诊断和分享按需打开；字幕记录与频道列表也默认关闭，同一时刻仅一个弹窗。

## 验证

node --test test/caption_browser.test.cjs 覆盖实际页面处理函数及正式字幕队列：迟到字幕、草稿隔离、源时间结束后继续阅读、长段分页、快速输入、暂停、重复事件、跳转重置和窄屏。Python 集成测试从公开 HTTP/WS 边界验证稳定短句先于语音终稿发布，翻译流式词块不作为字幕事件发送。真实云端与画面效果另保留本机截图，测试替身不得冒充真实验收。
