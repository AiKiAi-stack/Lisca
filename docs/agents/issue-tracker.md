# Issue tracker: GitHub

Issues and specs live in this repository's GitHub Issues. Use the `gh` CLI from this checkout.

- Create: `gh issue create --title "..." --body "..."`
- Read: `gh issue view <number>`
- List: `gh issue list`
- Comment or label: `gh issue comment <number> --body "..."`; `gh issue edit <number> --add-label "..."`
- Close: `gh issue close <number>`

PRs are not a triage request surface.
