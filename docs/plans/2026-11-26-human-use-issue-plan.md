# 2026-11-26：按实际观看需求收束 Issue 与接续计划

## Problem Statement

用户需要打开本地视频或直播，读到完整、连续、跟得上声音的字幕，暂停、跳转、停止后行为可靠。现有九个开放 Issue 混合产品目标、重复验收责任与已经停止的计量研究，难以确定下一步。一次 109 ms DOM 采样间隔曾使整段 1802 秒的 EOF、缓存跳转和资源结果一起无法收口。

本轮用户明确授权重新评估需求、回复并 decline 不合理项、排序、撰写方案，由 DeepSeekHarness CLI 实现与自测，再由 Codex 审核和构建。本轮继续使用已批准的公开 HTTP/WebSocket、真实浏览器、固定输入到评分报告的测试边界。

## Solution

保留四张独立执行票和一个父规格。按用户能观察的行为确定交付，按指标确定所需证据。历史失败、输入身份、原始记录、测量阈值和未知项继续可追溯。

## User Stories

1. 作为本地观看者，我希望整段播放到片尾并能回看已识别位置，以便顺利看完视频并控制识别费用。
2. 作为观看者，我希望暂停、未准备跳转和取消有明确结果，以便恢复正确内容或结束处理。
3. 作为中英文观看者，我希望数字、否定与快语速内容准确，以便理解原意。
4. 作为直播观看者，我希望连续观看期间延迟不会不断增长，以便持续跟上节目。
5. 作为观看者，我希望字幕与正在听到的语音对应，以便连贯阅读。
6. 作为维护者，我希望每项结论使用适合该指标的证据，以便定位真实缺口。
7. 作为用户，我希望账户额度故障能明确停止且完成清理，以便处理账户后继续使用。

## Implementation Decisions

- **优先 1 / #103，难度中：**复用现有采集器，增加逐指标的证据状态与原因。EOF、缓存跳转、会话数量、取消回执使用对应事件、检查点和请求账本；连续性、可读性与同步使用各自的时间/像素/声音证据。检查点不合格只影响对应控制结论。资源结论使用独立资源记录，不能从 DOM 样本推断。
- 原采集 `sampling.status`、50 ms 目标、100 ms 最大间隔和保守 `exit_ok` 语义保留。新增结论只声明得到直接证明的事实；采样不足的连续性与同步保持 unknown。109 ms 间隔不能凭空补插值或改判原整次采集有效。
- 账户 quota、认证或权限失败保持不可自动重试，清理及提示可用替身验证。额度恢复前可推进所有离线工作；本轮没有追加既有用满的真实实验额度。
- **优先 2 / #43，难度低至中、输入受阻：**复核已确认的中文 59 / 英文 67 参考身份、已存识别结果与归一化评分；数字、否定、指代另审。英文快语速独立参考仍未合格时如实列出缺失，不用同一 ASR 输出生成自己的标准答案。
- **优先 3 / #44，难度中、真实服务受阻：**先用已有真实播放器和替身识别验证选台、播放、暂停、恢复、停止与资源清理。真实中英 HLS 各 30 分钟及前后 5 分钟增长另列。公共额度、来源故障分别记录，不要求本地所有验收先通过才能启动独立的零 ASR 工作。
- **优先 4 / #63，难度高：**先审查 PR #106 当前差异，复用可用的 PCM/像素采集与区间评分；只修复能被具体反例证明的缺陷。每语至少 50 句、P95 ≤0.5 秒、最大 ≤1 秒、有声覆盖 ≥95% 保留。39/59 可测及覆盖区间不构成通过。
- ADR-0011 的浏览器输出时钟估计是本轮同步边界。物理输出误差上界与静音内源推进未知作为测量限制保留，取消“必须先解决 #70 才能完成全部产品工作”的依赖。没有新证据时结束计量研究。
- 父规格通过要求其真实产品项各自获得证据；代码、CI、运行时和产品分别记录。版本发布另按明确指令处理。

## Testing Decisions

只为本次具体行为新增回归，通过公开采集结果或 HTTP/WebSocket 的外部行为断言。先证明目标断言失败，再最小修复，再运行相邻回归。

### #103 本轮可独立交付切片

- 真实采集报告仍标记 109 ms 间隔超限，但独立、完整的媒体 EOF 证据可记为 observed；缓存跳转只有在媒体位置容差、画面检查和零新增会话均有证据时才能记为 observed。
- 浏览器未启动、输入身份不符、未到 EOF、无采样或缺少对应证据时，不能给出相应成功状态。
- 缺失/超时的跳转检查保持 unknown 或 failed；不能因文件播放完成推断跳转成功。
- 时间敏感指标在采样超限时保持 unknown，原始全局采样状态与退出码继续失败。
- quota 入口可用已有替身覆盖不可重试、零新增调用和清理，不为自测启动真实付费识别。
- 使用现有定向 Python 与前端回归；由 Codex 对固定提交分别审核 Standards 与 Spec，并执行 wheel 构建与已安装包检查。

## Execution Order And Blocking Edges

1. #103：离线报告切片可以立即实施；真实长片受额度和历史尝试上限约束。
2. #43：已有参考和历史评分核对可立即进行；缺失快语速参考的结论保持受阻。
3. #44：离线频道与控制检查可立即进行；真实直播受来源与识别额度约束。
4. #63：PR #106 的静态审查和零 ASR 回归可立即进行；新的真实同步受额度约束。

此处优先级是实施顺序，后三项离线检查均不依赖前项取得产品通过。#99 是汇总父规格，不是第五个实现任务。

## Out Of Scope

新增翻译/平台/模型、干净 Windows 和第二设备、物理扬声器计量、静音中不可观测源推进证明、新一轮无额度的付费重跑、合并或发布版本。
