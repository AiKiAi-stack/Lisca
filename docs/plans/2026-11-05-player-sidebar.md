# A 播放器与频道侧栏

2026-11-05，基线 `e93fb12`。用户在三套原型中选择 A，并要求加入 B 的示例频道、历史频道记录侧栏。
原型证据保留在 `codex/prototype-ui-flow` 的 `2f3c981`；实际实现分支为 `codex/ui-player-sidebar`。

## 行为

- 首页保留 A 的浅色界面、画面层级与宽高比；频道侧栏默认展开，可以收起。
- 侧栏包含示例频道、最近观看、频道列表管理。示例来源与 `examples/public-live-channels.m3u` 一致，
  仅提供入口，不新增来源可用性承诺。
- 选台只填入来源、显示名称并聚焦开始按钮，不启动识别。媒体实际开始播放后才记录最近观看。
- 最近观看去重并按最后观看顺序保留 20 项，保存于当前浏览器；可清空。
  本机文件路径、带用户名或密码的地址不记录，带查询参数或片段的地址只留当前页面内存。
  浏览器存储被禁用或已满时，当前页面仍可使用记录。
- 窄屏将同一个侧栏移入原生模态抽屉；选台后关闭抽屉，聚焦开始按钮。
- 播放器原有暂停、继续、字幕与恢复逻辑保持原接线。原来同时停止媒体和识别的按钮改称“结束观看”，
  与只停止识别的“仅播放”区分。
- 管理侧栏不向只读观众显示。新增标签提供中英文翻译。

## 验证

原验收项：A 的观看布局与 B 的内容导航可组合；选台不隐式计费；历史记录可恢复；窄屏可操作。
假设：侧栏只负责选源，保留独立的开始操作，可以兼顾切台便利与显式识别控制。
决定：实际媒体播放、记录写入和刷新恢复均验证后，才将这条路径标为通过。

- 代码：前端 124 项通过；相关 Python HTTP/共享路由 13 项通过。内嵌脚本与新脚本语法检查、
  仓库导入路径下的 Pylint 错误级检查通过。
- 浏览器：示例选择不自动开播；侧栏展开/收起正常。
- 离线识别夹具：真实 HLS 媒体时钟观察到 23.635989 秒；最近观看出现，刷新后恢复，重新选择记录
  没有创建新识别器（夹具计数仍为 1）。测试记录随后通过界面清空。
- 窄屏：实际页面 CSS 视口宽 389 px，页面滚动宽同为 389 px；抽屉展开、选台、关闭和开始按钮焦点通过。
  截图接口未能在该窄视口捕获图片，采用实际 DOM/无障碍树观察；未宣称手机实机通过。
- 原始证据保存在忽略目录 `logs/ui-sidebar-20261105/`；夹具使用临时配置，没有真实云端调用。
- 检查结束后恢复普通服务，首页与频道脚本 HTTP 200，夹具路由 HTTP 404；8002 保持单实例。

当前仅验证此 UI 切片；未运行整库 Python 回归、CI 或真实识别质量验收。
父规格 #34、发布核对 #46 及 ADR-0009 的既有正式发布缺口不因本轮 UI 回归而改变。

## UI 组件升级

2026-11-07 在 A 的画面优先布局与 B 的频道侧栏基础上，按 Impeccable 的 Operate 场景完成视觉与交互整理。
页面统一采用本地托管的 daisyUI 5.7.50（MIT）按钮、输入框、选项、页签、菜单、复选框与滑块，
图标统一为 Lucide static 1.69.0（ISC）。运行时不依赖 CDN；版本、来源、文件摘要和许可证分别保存在
`tools/webui_static/ui-vendor-manifest.json` 与 `tools/licenses/`。

- 来源输入与播放操作合并为主操作行，管理侧栏专注示例频道和最近观看，观众分享入口位于播放器工具栏。
- 设置改为原生居中对话框，按“识别服务 / 字幕样式 / 高级”分组；键盘焦点、关闭和窄屏滚动保持可用。
- 视觉检查修正了深色播放器次要按钮对比度、空态纯色图标、对话框布局和重复说明层级。
- 补齐浏览器自动请求的本地 SVG favicon，并覆盖桌面和局域网观众资源路由，清除首页控制台的 404。
- 前端 124 项、相关 Python HTTP/共享路由 13 项通过，内嵌脚本语法与 Pylint 错误级检查通过；
  定向浏览器回归也确认选台不发送识别请求，显式开始后才创建一次会话，并在回复前关闭频道对话框。
- 桌面与 389 px 窄屏交互复检期间，遍历频道侧栏和三个设置页后没有控制台错误、HTTP 4xx 或横向溢出。
- 离线夹具验证了媒体时钟、字幕显示、分享复制和 389 px 窄屏抽屉；计算样式检查确认主按钮 5.77:1、
  深色播放器次要按钮 15.14:1、播放器说明文字 8.47:1。Impeccable 静态扫描的三个对比度告警经
  浏览器计算样式核对为误报。
- 截图与扫描原文保存在忽略目录 `logs/ui-components-20261105/`。离线夹具只验证界面接线与模拟字幕，
  不代表真实识别质量、正式发布验收、整库 Python 回归或 CI 已通过。
