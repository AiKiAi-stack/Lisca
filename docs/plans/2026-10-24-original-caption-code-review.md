## Spec

初审两项 P1 行为缺陷，均已解决：

1. **同一退避窗口内的 HLS 与 ASR 故障使媒体停载。** HLS 网络错误调用 `stopLoad()`，识别故障随后被合并到同一次恢复。控制器优先执行识别恢复，而新的识别连接保留既有 HLS，未唤醒已停止的媒体加载器。它违反“同一次字幕故障累计等待不超过 2 秒，到上限媒体继续”。真实浏览器已复现：第二个识别器创建后 12 秒，媒体时间仍不能超过 0.3 秒。
2. **分享历史截断警告永久屏蔽后续字幕。** 历史超过 240 条后，新观众快照携带 `share_history_truncated` 错误；页面设置字幕错误样式，后续 `ready` / 字幕不会解除它。历史窗口提示应是非终态通知，不能阻断当前直播。此项是容量改动引入的回归，与第二设备实际验收延期分开处理。

`3050136` 让同次恢复先执行媒体动作、再重连识别，共用一次预算；纯识别恢复继续保留健康HLS。当前连接的时钟队列在晚到PTS时按序排空，即使ready/subtitle/end已排队、WS已正常关闭也无需等待下一条消息。历史截断改为独立非终态提示。独立Spec复审未发现可确认的剩余缺陷或修复回归。
