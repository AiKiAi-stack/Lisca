# 2026-10-27：原文字幕自动验收执行补充规格

### Problem Statement

用户不应替代理逐条手工标记声音起止。维护者需要实际声音、可见字幕与来源/时钟绑定的证据，判断启动、同步覆盖及长时体验是否达标。14个小PR已合并main867b532；合并不等于发布验收通过。

### Solution

复用已确认的公开HTTP/WS、实际播放器与评分报告边界，由代理完成自动采集、分析、复核和真实有限执行；每张执行票单独小PR，不堆大集成PR。

### User Stories

1. 作为观看者，我要字幕对应实际播放声音，而非只对应后端事件时间。
2. 作为观看者，我要完整稳定短句及时显示，不靠未完成草稿或拖慢媒体通过指标。
3. 作为用户，我要代理完成声音边界分析，不再要求我逐条填秒数或导出标注。
4. 作为维护者，我要每语至少50句的起止偏差和全部有声区间覆盖，缺失不被排除。
5. 作为维护者，我要固定原速HLS每语20次独立启动，冷/热、附加播放延迟与冻结分别报告。
6. 作为观看者，我要中英文直播各30分钟的稳定与延迟增长证据，错误全部保留。
7. 作为观看者，我要30分钟本地文件在识别未完成时播放，暂停、跳转、取消及资源可验证。
8. 作为维护者，我要报告绑定候选、输入、音轨与实际记录，测量不足明确未知/失败。
9. 作为用户，我要按决定排除本轮Windows和第二设备验收，原隐私与兼容保护继续保留。

### Implementation Decisions

- 从实际播放声音与实际可见画面取证；DOM/事件可辅助关联，不能单独冒充声学同步通过。
- 代理使用VAD、波形/频谱等独立估计并核查源声音区间，保留方法、参数和不确定度；不得伪装人工标注。无法可信判定记未知/失败，不交回用户逐条手标。
- 继续使用用户已确认的中文59条、英文67条参考及原输入哈希。英文MIT旧字幕配对已拒绝，更正稿仍provisional，不混入通过集。
- 启动沿用真正HLS、相同原速输入、完整分片/PCM身份与时钟。只修公开失败回归支撑的问题；不变速、不换有利来源、不弱化完整短句或阈值。
- 长测有上限、可取消，确认停止与资源释放；错误、重试、缓冲、冻结与字幕缺失保留。上限取消不冒充正常EOF。
- 运行前固定候选、输入和评分方法；有实际会话运行时不重启服务。代码完成、测量有效与指标通过分别记录。

### Testing Decisions

- 沿用此前确认的最高测试边界：公开CLI报告、真实浏览器HTTP/WS、媒体播放声音及可见画面。不新增产品私有验收API。
- 独立合成的已知声音/可见延迟与缺失记录先RED后GREEN，覆盖不确定度、无声、来源错配、暂停/跳转/冻结及脱敏；不由同一ASR输出反算参考答案。
- 同步每语至少50句；起始和消失偏差分别P95≤0.5秒、最大≤1秒；正常有声覆盖≥95%，缺失计分母。
- 启动每语至少20次独立有效尝试，首次稳定短句P95≤3秒；保留冷/热、误差上界、附加播放延迟及冻结。
- 两语直播各连续30分钟，后5分钟延迟中位数相对前5分钟增长≤1秒；来源固有延迟无可信基准记未知。
- 30分钟本地文件另验提前播放、未准备跳转、暂停、取消与资源峰值/释放，完成后控制新增识别请求0。
- 独立工作树TDD、每票小PR、双轴复核；不通过的真实结果不得自动勾选父问题。

### Out of Scope

- 用户明确“缺口5不用做”：本轮排除干净Windows及真实第二设备验收。#42/#45关闭为not_planned并移除发布阻塞，不计通过、不增加支持承诺；Windows历史、已有隐私和兼容回归保留。
- 不新增翻译、不发布版本、不改数字门槛。缺口3没有豁免；已确认参考不重做，英文快语速参考/关键误义继续保留未通过。

### Further Notes

执行复用已批准的#43/#44与原公开测试边界，不重新采访用户。补充三张可独立验证的小票：同步覆盖、固定HLS启动、长时体验。长时体验仅依赖同步取证能力，启动3秒通过不是它的前置条件。

## 2026-11-04 用户授权的门槛调整

用户在 PR89 合入后要求“修改 spec 后合入主分支”，依据当前候选 `027b325` 的 20+20 次真实启动、两语 30 分钟固定回放和同步 unknown 证据，调整预览验收口径：

- 启动：每语 20 次独立启动，首次稳定短句 P95 ≤ **5.5 秒**（预览门槛）；3 秒保留为未来目标，不能记为低延迟。冷/热、HLS 身份、采样、冻结和附加播放延迟照旧报告。
- 长时：中英各至少 30 分钟固定输入实时回放，0 公开错误、50 ms 采样有效、无来源缓冲、前后 5 分钟延迟代理增长 ≤1 秒；必须披露代理、暂停/缺失区间和 cap 取消。公网 HLS 30 分钟仍在来源矩阵单独验收。
- 同步：门槛不变（每语 50 句、P95 ≤0.5 秒、最大 ≤1 秒、覆盖 ≥95%）；当前 unknown，不阻塞 PR89 预览合入，但仍是正式发布 #46 的阻塞，不能写通过。
- 发布：只能称实验预览/代码切片，不更新正式标签；公开材料必须保留 5 秒级启动、同步 unknown、公网来源未全部验证的限制。
