# 01：配置识别服务并安全打开内容

**Parent:** [本地实现规格](../../../docs/plans/2026-10-23-original-caption-release-spec.md)。

**What to build:** 用户在本机页面配置识别服务、判断检查连接的结果，并能打开有效输入；无效输入给出可操作原因，不启动无意义的识别。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

**Approval:** 2026-10-23，用户已确认实现规格、测试边界、12 项粒度及依赖。此状态表示任务定义可执行，不代表阻塞项或外部前提已满足。

**Requirements:** R01/R02/R03/R04；A08/A09。来自 L05 及现有配置、输入链路缺口。

**Verification:** 公开 HTTP/WS 会话与真实浏览器操作，来源和识别服务使用可控替身。Windows 实际加密与干净安装由 11 验证。

- [ ] 未配置时解释配置入口，不创建识别；Key 遮罩显示，默认仅在本次运行有效。
- [ ] 检查连接明确区分发起连接与真实识别；自动/中文/英文原文入口不创建翻译请求。
- [ ] 无音轨、不可解码和已知浏览器不支持的输入在识别器创建前被拒绝；列表读取、平台解析和媒体拉流的错误阶段可分辨。
- [ ] 文件选择、路径和直接地址能够进入已有播放链路；用真实浏览器完成一次配置到打开的旅程。
- [ ] 配置、普通日志、URL、浏览器持久存储及诊断的自动回归不泄露假 Key 或会话凭证；无法分类的服务商错误保留未知。

**External prerequisites:** 自动化无付费 API 前提。真实 Windows 隐私结论不得由替身测试代替。
