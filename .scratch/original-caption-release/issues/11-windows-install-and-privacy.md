# 11：在干净 Windows 完成安装、观看与隐私验收

**Parent:** [本地实现规格](../../../docs/plans/2026-10-23-original-caption-release-spec.md)。

**What to build:** 陌生 Windows 用户可以从启动到首次中英文观看，能恢复常见安装错误并管理 Key、媒体副本和日志。

**Blocked by:** 01 配置识别服务并安全打开内容；02 在当前语音区间显示可读的原文短句；03 本地提前播放、静音放行与无进展退出；04 本地暂停跳转复用字幕并隔离旧会话；06 统一故障恢复预算并证明停止后没有新请求。

**Status:** deferred

**Deferral:** 2026-10-23 用户确认当前只有 Linux 设备，暂时没有第二台局域网设备和干净 Windows 环境，要求本任务后续再实现。保留验收标准和依赖，不计完成。

**Approval:** 2026-10-23，用户已确认实现规格、测试边界、12 项粒度及依赖。此状态表示任务定义可执行，不代表阻塞项或外部前提已满足。

**Requirements:** R01/R02/R09；A08/A09。来自 L05。

**Verification:** 干净 Windows 上实际启动、浏览器观看和用户绑定加密往返。安装依赖检查和导入退出码只是子证据。

- [ ] 记录 Windows、浏览器、Python、网络和安装步骤；非系统盘、中文/空格路径走通，无需改源码。
- [ ] 缺依赖、首次安装失败、端口占用、重复启动给出可执行恢复路径；只使用既定 8002 WebUI 入口。
- [ ] 实际完成一次中文和英文观看与停止；新用户说明与实际页面步骤一致。
- [ ] 默认 Key 仅内存，选择保存后实际 DPAPI 加密，删除后不可再加载；不能用 Linux 跳过结果视为通过。
- [ ] 日志、URL、浏览器持久存储和诊断不泄露 Key/会话凭证/敏感来源参数；配置删除与媒体清理分别说明。
- [ ] 提供实际缓存、媒体、日志、配置位置与清理记录；所有失败保留证据。

**External prerequisites:** 独立干净 Windows 环境和所需浏览器；真实首次识别需用户授权配置。不能访问该环境时保持受阻。
