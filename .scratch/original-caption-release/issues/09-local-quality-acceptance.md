# 09：完成中英文本地质量与长文件体验验收

**Parent:** [本地实现规格](../../../docs/plans/2026-10-23-original-caption-release-spec.md)。

**What to build:** 中英文观看者能按 PRD 完成本地字幕旅程，维护者获得可核对的准确率、实际画面同步和控制请求证据。

**Blocked by:** 01 配置识别服务并安全打开内容；02 在当前语音区间显示可读的原文短句；03 本地提前播放、静音放行与无进展退出；04 本地暂停跳转复用字幕并隔离旧会话；06 统一故障恢复预算并证明停止后没有新请求；07 把评分报告绑定到正确的识别输入。

**Status:** waiting-external-prerequisites

**Approval:** 2026-10-23，用户已确认实现规格、测试边界、12 项粒度及依赖。此状态表示任务定义可执行，不代表阻塞项或外部前提已满足。

**Requirements:** R03–R07/R09；A01/A02/A06/A07。来自 L02，使用 L01 的证据能力。

**Verification:** 固定中英文媒体、独立人工参考集、真实识别、真实播放器；先离线稳定行为，再执行有上限的真实样本。

- [ ] 中文原文件指定约 5.1 秒和 23.8 秒两处对应，并审阅全片；英文媒体独立保留画面与原文证据。
- [ ] 中英文各至少 5 分钟清晰单人参考集：中文 CER ≤10%、英文 WER ≤15%；快语速各至少 1 分钟另报，关键否定/数字/指代逐条复核。
- [ ] 每种语言至少 50 个短句，开始和消失偏差绝对值分别 P95 ≤0.5 秒、最大值 ≤1 秒；正常有声片段覆盖 ≥95%，缺失计入分母。
- [ ] 至少 30 分钟本地媒体在识别未完成时即可播放，覆盖未准备区间跳转、暂停、取消、资源峰值和释放；完成后控制新增识别请求为 0。
- [ ] 首次准备在固定样本重复至少 3 次，注明冷/热启动与缓存；不把本地提前处理报告成直播延迟。
- [ ] 可读性、控制、终稿修订与画面指标均给结论；失败和受阻保留，不改阈值或用部分成功覆盖全项。

**External prerequisites:** 固定中英文参考媒体/文字及用户授权的识别配置。缺少时不自动启动付费调用，不标记通过。

**当前前提（2026-10-24）:** 离线实现依赖01–07已完成；尚缺本轮真实识别配置和独立参考听审。两语五分钟单说话人及原速一分钟候选、源片段哈希/许可证已保存在项目，见[素材说明](../../../docs/research/2026-10-24-single-speaker-acceptance-media.md)。未执行付费识别、真实准确率、同步覆盖或直播长测，本任务保持未完成。
