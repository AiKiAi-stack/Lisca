# 02：在当前语音区间显示可读的原文短句

**Parent:** [本地实现规格](../../../docs/plans/2026-10-23-original-caption-release-spec.md)。

**GitHub:** https://github.com/AiKiAi-stack/stream-with-asr/issues/36

**What to build:** 观看者在真实播放器中看到与当前语音时间对应的完整短句，能阅读长句、快语速内容，并在全屏和窄屏继续操作。

**Blocked by:** None (can start immediately).

**Status:** completed

**Approval:** 2026-10-23，用户已确认实现规格、测试边界、12 项粒度及依赖。此状态表示任务定义可执行，不代表阻塞项或外部前提已满足。

**Requirements:** R05/R06；A01/A02/A06/A10。来自 L02。

**Verification:** 公开会话、固定可播媒体、可控词时间和真实播放器；读取媒体时间与实际可见字幕。快速 Node 回归作为补充。

- [x] 画面只显示稳定短句或终稿，草稿仅在记录修订；不使用翻译阅读队列调度原文。
- [x] 长段按语音和语义切成短句，不在结束时集中倾倒，也不为旧台词排队覆盖后续语音。
- [x] 整句修正和撤回正确生效，过期及废弃文本不复现；已过期结果保留记录。
- [x] 中英文均用真实播放器检查显示与消失时间，包含缺失区间，不以事件到达代替实际显示。
- [x] 桌面最多两行、无裁切；字号、位置、对比度、字幕开关、全屏及窄屏可用且不挡住必要控制。
- [x] 人为调度造成的连续不足 0.6 秒换页为 0，语音本身的短句单独标注。

**External prerequisites:** 使用本地固定媒体与模拟识别即可验证行为；真实语言准确率由 09 独立验证。
