# 08：局域网观众正确复用主机原文字幕

**Parent:** [本地实现规格](../../../docs/plans/2026-10-23-original-caption-release-spec.md)。

**What to build:** 观众加入主机同一场直播，看到当前媒体对应的原文字幕；不会额外识别、读取 Key 或保留已停止会话的访问权。

**Blocked by:** 05 直播字幕故障有界等待并恢复当前时间轴；06 统一故障恢复预算并证明停止后没有新请求。

**Status:** deferred

**Deferral:** 2026-10-23 用户确认当前只有 Linux 设备，暂时没有第二台局域网设备和干净 Windows 环境，要求本任务后续再实现。保留验收标准和依赖，不计完成。

**Approval:** 2026-10-23，用户已确认实现规格、测试边界、12 项粒度及依赖。此状态表示任务定义可执行，不代表阻塞项或外部前提已满足。

**Requirements:** 既有共享兼容边界；A10。来自 L06。

**Verification:** 公开主机/观众 HTTP/WS 会话回归，加第二台局域网设备的真实播放器记录；模拟与真实设备结论分开。

- [ ] 观众复用唯一主机识别，新增识别与翻译请求为 0。
- [ ] 加入、静音、字幕等待/恢复及重连后，字幕归属和媒体时间正确。
- [ ] 最多 3 台观众；离开释放容量，观众不能修改主机配置或访问 Key/主机诊断凭证。
- [ ] 停止后媒体与字幕链接失效；下一场直播没有上一场结果或旧观众连接污染。
- [ ] 至少一台第二设备保留观看和停止证据；没有设备时该部分受阻，不以同机测试代替。

**External prerequisites:** 同一局域网第二设备；真实识别需另有授权配置，使用替身时明确记录模拟范围。
